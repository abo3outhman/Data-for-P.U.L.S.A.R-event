## How to Use a Coupon Code

1. Add products to your cart.
2. Go to checkout.
3. In the **"Coupon Code"** field, enter the code.
4. Click **"Apply"**.
5. The discount is automatically applied to your order total.
6. Complete the checkout.

> ⚠️ Only one coupon code can be used per order (except for automatic offers).

## Coupon Code Rules

1. Coupon codes are **case-sensitive** (e.g., `AUTUMN25` ≠ `autumn25`).
2. Coupons have an **expiration date**.
3. Coupons may have **minimum order requirements**.
4. Coupons may have **maximum discount limits**.
5. Coupons may be **category-specific**.
6. Coupons cannot be combined (one per order).
7. Coupons cannot be applied to orders already placed.
8. Some coupons are **customer-specific** (sent by email to selected customers).

## Expired Coupons

If you try to use an expired coupon:
- You'll see an error: "This coupon has expired."
- The order total is not changed.
- You can try a different coupon or proceed without a discount.

## Coupon Not Working?

If your coupon doesn't work:

1. Check the **expiration date**.
2. Check the **minimum order requirement**.
3. Check the **category restrictions**.
4. Check the **spelling** (case-sensitive).
5. Check if you're **logged in** (some coupons require an account).
6. Check if you've **used it before** (some are one-time use).
7. Contact us if it should work but doesn't:
   - Email: `support@dzshop.dz`
   - Hotline: 3030
